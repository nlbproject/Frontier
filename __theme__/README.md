# Тема «Фронтира» (Rangers 3) для NLB

Тема из экспорта «Фронтира» в INSTEAD (github.com/nlbproject/instead-frontier: theme.ini,
шрифты, картинки окна, звук щелчка), разложенная как тема NLB: `theme.ini`,
`theme_standard.lua`, `fonts/`, `gfx/`.

Как подключить: положить этот каталог как `__theme__` в каталог книги Frontier — веб-плеер
NLBW (в том числе запущенный из редактора) и пакеты `.nlbpack` берут тему оттуда.

Тема рассчитана на раскладку STANDARD (экран 800×600: текст слева, инвентарь справа столбцом,
картинка страницы — в окне текста под заголовком, `scr.gfx.mode = fixed`). Чтобы книга
открывалась в STANDARD по умолчанию, поставьте в свойствах книги тему STANDARD. В режиме VN
плеер берёт из неё только шрифты, цвета и кнопку меню.
